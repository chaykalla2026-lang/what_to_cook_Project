# Что приготовить?

Настольное приложение для хранения рецептов, учёта домашних продуктов и подбора блюд.

**Автор:** Чайка Алла
**Формат работы:** индивидуальный проект  
**Учебный модуль:** PyQt  
**Основные технологии:** Python, PyQt6, SQLite  

## Идея проекта

«Что приготовить?» — приложение, которое помогает выбрать рецепт блюда, которое можно приготовить из продуктов, имеющихся дома.

Пользователь сможет вести собственную книгу рецептов, указывать доступные продукты и получать список подходящих блюд. Если каких-то ингредиентов не хватает, программа покажет их и позволит сохранить список покупок.

Особенность проекта — подбор рецептов с учётом количества продуктов, числа порций и доступного времени приготовления. Рецепты пользователь добавляет самостоятельно.

## Для кого создан проект

Приложение предназначено для людей, которые хотят:

- хранить любимые рецепты в одном месте;
- выбирать блюда из имеющихся продуктов;
- заранее понимать, что нужно купить;
- пересчитывать ингредиенты на другое число порций;
- тратить меньше времени на выбор блюда.

## Пример использования

1. Пользователь добавляет продукты, которые есть дома, и указывает их количество.
2. Выбирает желаемое число порций и максимальное время приготовления.
3. Программа сравнивает домашние запасы с ингредиентами рецептов.
4. Пользователь видит блюда, для которых хватает продуктов, и варианты с недостающими ингредиентами.
5. Открывает рецепт, читает инструкцию и при необходимости сохраняет список покупок.
6. Во время приготовления может воспользоваться таймером.

## Планируемые возможности

### Книга рецептов

- Добавление, просмотр, редактирование и удаление рецептов.
- Сохранение названия, категории, фотографии, инструкции, времени приготовления и числа порций.
- Добавление ингредиентов с указанием количества.
- Поиск рецептов по названию.
- Фильтрация по категории и времени приготовления.
- Добавление рецептов в избранное.

### Домашние продукты

- Добавление продуктов и указание доступного количества.
- Изменение количества и удаление продуктов из списка запасов.
- Выбор единицы измерения: граммы, миллилитры или штуки.

### Подбор блюд

- Поиск рецептов, для которых хватает имеющихся продуктов.
- Отображение недостающих ингредиентов и их количества.
- Ограничение по времени приготовления.
- Пересчёт ингредиентов на выбранное число порций.

### Дополнительные возможности

- Сохранение списка покупок в TXT.
- Экспорт списка рецептов в CSV.
- Таймер приготовления с запуском, паузой и сбросом.
- Наглядное отображение обеспеченности рецепта продуктами.
- Настройка оформления приложения.

## Интерфейс приложения

Планируется несколько форм:

1. **Главное окно** — вкладки «Рецепты», «Продукты» и «Подбор».
2. **Карточка рецепта** — фотография, ингредиенты, инструкция, расчёт порций и таймер.
3. **Редактор рецепта** — создание и изменение рецепта.
4. **Окно продукта** — название, единица измерения, количество и срок годности.
5. **Настройки** — параметры отображения.

## База данных

Планируется использовать связанные таблицы:

- **recipes** — название, категория, инструкция, фотография, время приготовления, базовое число порций и отметка избранного;
- **ingredients** — справочник ингредиентов и их единиц измерения;
- **recipe_ingredients** — связь рецептов с ингредиентами и необходимое количество каждого ингредиента;
- **pantry** — домашние запасы: ингредиент, доступное количество и срок годности.

Программа будет создавать необходимые таблицы при первом запуске. Будут реализованы чтение, добавление, изменение и удаление данных.
