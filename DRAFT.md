# Черновой интерфейс, 16 ноября 2026 года

Этот этап реализует расположение виджетов и переходы между окнами по разделу 5 ТЗ. Данные берутся из небольших CSV-примеров. SQLite, сохранение изменений и алгоритмы будут подключаться следующими этапами.

## Запуск

1. Открыть папку проекта в PyCharm.
2. Выбрать интерпретатор виртуального окружения. Локально подготовлено `.venv/bin/python`.
3. Установить зависимости командой `python -m pip install -r requirements.txt` в терминале этого окружения.
4. Запустить `main.py`.

Для запуска из терминала в папке проекта на Mac: `.venv/bin/python main.py`.
Папки `ui` и `data` должны находиться рядом с `main.py`. Пути определяются относительно файла программы, поэтому запуск из другой рабочей папки также поддерживается.

Проверено на macOS, Python 3.14.6, PyQt6 6.12.1. Версия Python 3.12 из ТЗ и Windows на данном этапе отдельно не проверялись. Виртуальное окружение не загружается в репозиторий.

## Что уже работает

- Главное окно с вкладками «Рецепты», «Справочник», «Холодильник», «Подбор».
- Меню «Файл», «Инструменты», «Справка».
- Чтение пяти CSV и отображение рецептов, ингредиентов и запасов в таблицах.
- Выбор строки мышью и открытие карточки или редактора соответствующей записи.
- Переход из карточки в редактор рецепта и макет единственного таймера.
- Открытие формы ингредиента из справочника, рецепта и холодильника.
- Отображение состава выбранного рецепта через связи `recipe_id` и `ingredient_id`.
- Окна настроек, таймера и инструкции; закрытие дополнительных окон при закрытии главного.
- Переключение подписи базы КБЖУ при выборе граммов, миллилитров или штук.

## Что оставлено на следующий этап

Сохранение и удаление, подбор, пересчёт порций, вычисление КБЖУ, избранное, фильтры, сортировка, экспорт, выбор фотографии и сам отсчёт таймера. Соответствующие действия неактивны. Изменение полей в открытых формах пока не сохраняется.

Открытие записей выполняется кнопками. Двойной щелчок, управление состояниями кнопок при выборе с клавиатуры, модальность редакторов и проверка несохранённых изменений будут добавлены вместе с редактированием данных. Числа в карточке не выдаются за результат подбора: в расчётных ячейках стоят прочерки.

## Временные данные и будущая БД

Все пять файлов уже созданы и подключены к программе. Разделитель — точка с запятой, первая строка содержит имена полей, кодировка — UTF-8. Для десятичных чисел в CSV используется точка. Пустые четыре поля КБЖУ означают неизвестные значения, а введённые нули — известные нули.

| Файл | Содержимое и связь с виджетами | Будущая таблица SQLite |
| --- | --- | --- |
| `data/recipes.csv` | Рецепты для главной таблицы, карточки и редактора | `recipes` |
| `data/ingredients.csv` | Общий справочник, единицы, КБЖУ и варианты выбора продукта | `ingredients` |
| `data/recipe_ingredients.csv` | Строки состава в редакторе и ингредиенты карточки | `recipe_ingredients` |
| `data/fridge.csv` | Таблица домашних запасов и форма изменения количества | `fridge` |
| `data/app_settings.csv` | Начальное число персон для подбора, карточки и настроек | `app_settings` |

Например, строка `1;2;100` в `recipe_ingredients.csv` означает: для рецепта с `id=1` требуется 100 единиц ингредиента с `id=2`. Название и единица берутся из `ingredients.csv`. Строка `2;250` в `fridge.csv` означает, что дома есть 250 единиц этого ингредиента. Идентификаторы в связанных файлах должны существовать в справочниках; единица продукта должна быть `г`, `мл` или `шт`.

В примерах есть два рецепта, три ингредиента и три запаса. Данные о КБЖУ не выдумываются: соответствующие поля оставлены пустыми. После ручного изменения CSV приложение нужно перезапустить. Если оставить только заголовки, таблицы будут пустыми.

В следующем этапе появится один файл `recipes.sqlite3` с пятью таблицами из ТЗ. Чтение CSV будет заменено запросами `SELECT`, а формы получат операции записи. До этого создавать пустые файлы с расширением `.db` не требуется.

## Связь с пройденными уроками

| Приём | Материал |
| --- | --- |
| `QApplication`, окна, `show()`, `close()`, хранение окон в атрибутах | «Выбираемся из тьмы консоли» |
| `.ui`, `uic.loadUi`, компоновки, `QComboBox`, `QSpinBox` | «Делаем красиво» |

Дополнительные виджеты ограничены `QCheckBox` и `QDoubleSpinBox`, указанными в ТЗ. Для заполнения числовых полей и флажка используются два небольших дополнения к показанным в уроках методам: `setValue()` и `setChecked()`. Они устанавливают значение поля и состояние флажка. Код чтения файлов использует стандартные средства Python.

## Как показать черновик

1. Запустить `main.py`, проверить четыре вкладки и меню.
2. На вкладке «Рецепты» щёлкнуть строку и нажать «Открыть».
3. Из карточки открыть редактор; оттуда — «Новый ингредиент».
4. На вкладке «Холодильник» выбрать строку и открыть изменение количества.
5. Через меню открыть настройки, макет таймера и инструкцию.

На этом этапе демонстрируются устройство интерфейса и чтение примеров. Выполнение остальных пунктов итогового ТЗ будет отмечаться по мере разработки.
