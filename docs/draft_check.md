# Проверка чернового интерфейса

Дата: 16 ноября 2026 года.

Среда: macOS, Python 3.14.6, PyQt6 6.12.1. Проверка выполнена в Qt с offscreen-платформой; взаимодействие мышью для выбора строки воспроизведено через QtTest. QtTest используется только при проверке и не импортируется приложением.

Проверено:

- загрузка восьми `.ui` и запуск главного окна;
- четыре вкладки в согласованном порядке;
- чтение пяти CSV: два рецепта, три ингредиента, три запаса и настройка числа персон;
- выбор строки мышью включает кнопки открытия и редактирования;
- карточка открывает выбранный рецепт и показывает связанные ингредиенты;
- редактор открывается с исходными значениями, новая форма очищена;
- переход к новому ингредиенту из редактора рецепта;
- единицы измерения не дублируются в выпадающем списке;
- подпись базы КБЖУ переключается, флажок включает поля;
- форма запаса показывает правильное количество и блокирует выбор продукта при редактировании;
- настройки показывают число персон из файла;
- повторное открытие макета таймера использует то же окно;
- справка загружается из TXT;
- таблицы просмотра защищены от прямого редактирования;
- главное окно закрывает дополнительные окна.
- запуск из другой рабочей папки сохраняет доступ к `.ui` и CSV;
- взаимодействие с черновиком не изменяет файлы CSV.

Результат: перечисленные проверки пройдены. Созданы снимки `previews/main.png`, `previews/catalog.png` и `previews/recipe.png`.

Остальные сценарии приёмки итогового ТЗ, настоящая работа таймера, сохранение, SQLite, расчёты, Windows и Python 3.12 на этом этапе не проверялись: соответствующая реализация ещё не выполнена.
