# Проверка соответствия ТЗ от 26 ноября 2026 года

Проверяется версия 0.4 проекта «Что приготовить?» по ТЗ версии 1.1 от 26 ноября: исходные обязательные требования от 12 ноября и согласованное уточнение двух тем оформления. Исходная версия на GitHub перед изменениями — коммит `3d853d4dd49e3f70cef25a440a668219654c15e7`. Исправления выполнены локально; автоматической загрузки в репозиторий не было.

## Результат и условия

В проекте 42 автоматических теста: 13 проверок базы и расчётов, 9 проверок окон и 20 дополнительных приёмочных проверок. Они покрывают все 33 сценария TC-01–TC-33 из раздела 11 ТЗ, а также найденные при проверке ошибки.

Проверка выполнена на macOS 26.6.2 ARM64, Python 3.12.14 и Python 3.14.6, PyQt6 6.12.1, Qt 6.12.0. Исходные функции приложения проверены; окончательная приёмка Windows-сборки пока не проведена.

Окна создаются с платформой Qt `offscreen`; действия выполняются через настоящие виджеты и их сигналы. Диалоги подтверждения и выбора файлов в автоматических тестах получают заданные ответы. Снимки основных окон дополнительно просмотрены визуально, включая главное окно 1024 × 700. Автоматические тесты не подтверждают удобство нативных диалогов Windows.

Все данные проверок находятся во временных папках. Пользовательская база и фотографии не изменяются; примеры со снимков не добавляются при первом запуске.

## Исправления

1. При включённом флажке «КБЖУ известно» нельзя сохранить пустые четыре поля. Называются недостающие показатели; известные нули сохраняются как нули.
2. Поля количества принимают точку и запятую одинаково. Исправлена зависимость от локали, при которой `1.25` могло превращаться в `125`. Недопустимый ввод не округляется и не заменяется другим значением.
3. Ошибки показываются рядом с полями, неверные поля подсвечиваются, введённый текст остаётся. Сообщение о дубле называет существующий ингредиент.
4. В редактор рецепта добавлен поиск ингредиента; создание нового продукта из этого окна сохраняет черновик и выбирает созданный ингредиент.
5. Кнопки изменения и удаления строки состава недоступны без выбранной строки. У неизвестного КБЖУ есть пояснение, для пустого избранного и устаревшего подбора выведены отдельные сообщения.
6. Главное окно имеет минимум 1024 × 700; ширину столбцов можно менять вручную.
7. Ошибка открытия базы содержит её путь и причину. Повреждённый файл не подменяется пустой базой.
8. Реализованы светлая и тёмная темы без изменения размера текста. Настройки сохраняются одной операцией в app_settings. Проверены отмена, перезапуск, ошибка записи и миграция базы предыдущей версии с сохранением рецептов, состава, запасов и избранного. Тема применяется ко всем окнам и не сбрасывает текущий подбор.
9. Подготовлены зависимости, сценарий и инструкция сборки Windows. Сам `.exe` пока не проверен.

## Производительность

Отдельная временная база: 500 рецептов, 500 ингредиентов, 50 строк состава в каждом рецепте — 25 000 связей. Замер на Mac ARM64, Python 3.12.14, Qt `offscreen`:

| Действие | Время | Предел ТЗ |
| --- | --- | --- |
| Создание окна и загрузка списка | 0,451 с | Отдельно не задан |
| Поиск по названию | 0,004 с | 1 с |
| Полный подбор | 0,126 с | 2 с |

В указанной среде пределы поиска и подбора выполнены. Объём ОЗУ и характеристики накопителя отдельно не подтверждались; замер не подтверждает скорость на любом компьютере с 8 ГБ ОЗУ.

## Проверка кода и ресурсов

Синтаксис Python и XML восьми форм корректен. Выбранные правила Ruff для ошибок, импортов и длины строк до 79 символов выполняются. Расчёты отделены от интерфейса; используется одна SQLite-база с пятью таблицами, внешними ключами и транзакциями. Для запуска нужен только PyQt6 из `requirements.txt`; стандартные модули отдельно не устанавливаются.

Команда проверки из папки проекта:

```sh
python -m unittest discover -s tests -v
```

## Что ещё требуется

- Выполнить `build_windows.bat` на Windows 10/11 x64 и проверить итоговый `WhatToCook.exe` по `docs/windows_build.md`, включая компьютер без Python.
- Проверить нативные диалоги и удобство на целевом компьютере Windows. Пояснительная записка автора сохранена без изменений; презентация подготовлена отдельно.
- Светлая и тёмная темы реализованы и проверены. Размер текста не настраивается.

Сборка `.exe` и её работоспособность пока не считаются подтверждёнными. Исходные функции и расчёты прошли проверку на Mac, в том числе на версии Python из ТЗ.
