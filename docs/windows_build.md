# Сборка и проверка Windows

На 24 ноября 2026 года подготовлен сценарий сборки. Сам `.exe` ещё не собран и не проверен на Windows. Проверка исходного приложения на Mac не заменяет этот этап.

## Сборка

1. На Windows 10/11 x64 установить Python 3.12 x64 с Python Launcher. Проверить в терминале: `py -3.12 --version`.
2. Распаковать исходный проект целиком. Рядом с `main.py` должны находиться папки `ui`, `data`, `tests`, файлы зависимостей и `build_windows.bat`.
3. Запустить `build_windows.bat`. Он создаёт отдельное окружение `.venv-build`, устанавливает зависимости из `requirements-build.txt`, запускает тесты и собирает один файл PyInstaller. При ошибке выполнение останавливается с сообщением.
4. Найти результат `dist/WhatToCook.exe`. В сборку включаются восемь форм, `data/schema.sql` и `data/help.txt`. Личная база и фотографии в сборку не включаются.
5. Скопировать только `.exe` в отдельную папку и пройти проверку ниже. Пользователю готового `.exe` Python для запуска не нужен.

В `requirements-build.txt` закреплён PyInstaller 6.22.3. Установка и сам сценарий пока не проверены на Windows, поэтому возможные ошибки сборки нужно сохранить и исправить до итоговой сдачи. Способ включения ресурсов и режим одного файла описаны в [документации PyInstaller](https://pyinstaller.org/en/stable/usage.html). Сборку для Windows выполняют на Windows — [пояснение разработчиков](https://pyinstaller.org/en/stable/operating-mode.html).

## Проверка готового файла

- Запустить `.exe` из папки с пробелами и русскими буквами, например «Учебный проект».
- Открыть все четыре вкладки, редакторы, настройки, справку и таймер.
- В «О программе» проверить постоянную папку данных. База должна находиться в пользовательской папке, а не во временной папке PyInstaller.
- Создать ингредиент, рецепт без фото и запас. Добавить фото через редактирование, затем убрать исходный файл фотографии из первоначальной папки. Карточка должна показывать сохранённую копию.
- Проверить `1,25` и `1.25` в количестве, подбор, порции, избранное, TXT и CSV.
- Запустить таймер, скрыть его окно, открыть снова, поставить на паузу и продолжить.
- Закрыть и снова открыть `.exe`: рецепты, запасы, фото, избранное и настройки должны сохраниться; таймер начинается заново.
- Повторить запуск на компьютере без установленного Python. Зафиксировать дату, версию Windows и результат в `docs/test_report.md`.

Папки `.venv-build`, `build`, `dist` и автоматически созданный `.spec` в исходники на GitHub не загружаются. Готовый `.exe` входит в итоговую поставку отдельно.
